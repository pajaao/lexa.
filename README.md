## O que é o Lexa?

O Lexa é uma biblioteca jurídica gratuita para encontrar e ler alguns dos textos federais mais utilizados no Brasil. Você pode abrir uma coleção, ir direto a um artigo, pesquisar uma expressão e compartilhar o link do trecho que está consultando.

O projeto foi pensado para estudantes, profissionais e qualquer pessoa que queira consultar esses textos com uma navegação simples. O acesso é livre, sem cadastro, no computador ou no celular.

## Encontre o que precisa

Na busca da página inicial, digite o nome ou a sigla de uma coleção, ou indique uma referência completa:

| Você pode escrever | O que será encontrado |
| --- | --- |
| `Art. 60 CF` ou `CF art. 60` | Artigo 60 da Constituição Federal |
| `Art. 186 CC` | Artigo 186 do Código Civil |
| `Art. 1.022 CPC` | Artigo 1.022 do Código de Processo Civil |
| `Art. 54-A CDC` | Artigo 54-A do Código de Defesa do Consumidor |
| `ADCT art. 1` | Artigo 1 do ADCT |
| `SV 13` | Súmula Vinculante 13 |
| `dignidade` ou `educação` | Entradas que contêm a expressão, agrupadas por coleção |

Clique no resultado para abrir o texto. Quando houver apenas uma referência encontrada, você também pode pressionar **Enter**.

Dentro de cada coleção, a busca aceita números e expressões do texto, como `superendividamento`. Ela ignora diferenças entre letras maiúsculas, minúsculas e acentos. Na página inicial, palavras e expressões também são procuradas nos artigos, títulos e materiais de aplicação das súmulas, com resultados agrupados por coleção. Digite pelo menos dois caracteres. Cada resultado mostra um trecho com destaque; ao abri-lo, a busca continua no leitor. Use os filtros de área e “Mostrar mais” para explorar os resultados. Redações riscadas e ocorrências em precedentes ou observações são identificadas. As coleções também continuam sendo encontradas pelo nome, área, sigla ou descrição.

## Uma leitura mais confortável

- **Estrutura da norma:** partes, livros, títulos, capítulos e seções têm destaque próprio; parágrafos, incisos e alíneas usam recuos para facilitar a leitura.
- **Índice expansível:** abra as divisões, consulte seus intervalos e selecione um capítulo ou uma divisão inteira. A barra de leitura indica a posição atual.
- **Tema claro ou escuro:** escolha o que fica mais confortável para você.
- **Fonte e espaçamento ajustáveis:** abra “Ajustes de leitura” para escolher o tamanho do texto e o espaço entre linhas e parágrafos. No celular, esses controles ficam recolhidos para liberar espaço. As preferências ficam salvas neste navegador.
- **Modo de foco:** concentre a tela no texto e nos controles de leitura. Use “Sair do foco” ou a tecla Esc para voltar.
- **Continuar leitura:** retome pela biblioteca o último artigo ou súmula consultado. O registro fica somente neste navegador e pode ser removido no próprio cartão.
- **Favoritos:** use a estrela para guardar uma entrada no navegador atual. A página “Favoritos”, no menu, reúne as marcações por norma, com busca e remoção individual.
- **Cópia com referência:** no menu “Copiar” de cada entrada, copie o texto com a identificação da norma, a edição e os links de consulta, ou copie somente o link. Nas súmulas, a cópia inclui o enunciado, separado dos precedentes. Trechos riscados são identificados no texto copiado.
- **Contexto das súmulas:** abra a seção de precedentes, jurisprudência e observações quando precisar aprofundar a consulta.
- **Histórico de versões:** acompanhe as edições incorporadas e compare as diferenças registradas.

Os favoritos ficam no seu dispositivo e navegador. Eles não são sincronizados entre aparelhos e podem ser perdidos ao limpar os dados do navegador.

## Instalar e consultar offline

O Lexa pode ser instalado como aplicativo web, sem loja de aplicativos:

- **Android e computador:** abra o site e procure a opção de instalar no menu ou na barra de endereços do navegador. Quando disponível, o botão “Instalar Lexa” aparece em “Instalar e usar offline”, no rodapé.
- **iPhone e iPad:** abra no Safari, toque em **Compartilhar → Adicionar à Tela de Início**.

Na primeira visita, o Lexa guarda a interface e passa a guardar os conteúdos consultados. Em **“Instalar e usar offline”**, no rodapé, veja quais normas estão disponíveis e use **“Preparar biblioteca completa offline”** para baixar todo o acervo, a busca e o histórico dessa edição. Aguarde a confirmação de biblioteca completa antes de depender de todo o acervo sem conexão. PDFs e páginas oficiais externas precisam de internet. O navegador pode remover os dados offline para liberar espaço.

Quando uma nova versão estiver pronta, o site oferecerá **“Atualizar agora”**. A atualização recarrega a página e preserva favoritos e preferências. Durante uma consulta offline, confira a edição indicada: ela corresponde ao conteúdo salvo no dispositivo. A instalação não é necessária para usar o site.

## De onde vêm os textos?

As edições dos códigos e da Constituição são extraídas das páginas oficiais do **Planalto**, incorporadas ao site após revisão. Os PDFs utilizados na formação da base permanecem arquivados no repositório. CPP, ECA, Lei de Execução Penal, Lei Maria da Penha, Lei de Improbidade Administrativa e Lei de Licitações integram a biblioteca e o monitoramento das fontes oficiais. A CLT também integra a biblioteca e o monitoramento; o PDF completo de 205 páginas fica arquivado, com os anexos disponíveis no documento original.

As súmulas vinculantes usam o PDF fornecido ao projeto, que declara consulta ao STF em **16/10/2026** e contém **63 entradas**, numeradas de 1 a 63. O site preserva as indicações desse documento, incluindo a **SV 9 como cancelada** e a **SV 30 como pendente de publicação**.

Cada coleção mostra sua edição e procedência em **“Sobre esta versão e a fonte de origem”**, com links para conferência.

> **Para utilizar os textos:** confira a edição consultada, a redação e as notas na fonte oficial. A data de coleta indica quando uma fonte foi consultada; o sistema não calcula automaticamente a vigência ou o início dos efeitos de cada alteração.

## Como as atualizações funcionam?

**Códigos e Constituição:** uma rotina diária consulta as fontes do Planalto. Quando detecta diferenças, prepara uma proposta de atualização no GitHub — chamada *pull request* — com relatório e prévia. A incorporação depende de revisão e aceitação pelo mantenedor. Depois disso, o site é publicado automaticamente.

**Súmulas vinculantes:** a atualização é periódica e manual, a partir de uma nova edição conferida pelo mantenedor. A coleta automática do STF está pausada por dificuldades de acesso ao portal.

Na página **[Atualizações](https://pajaao.github.io/lexa./#/atualizacoes)**, o primeiro registro estabelece a referência inicial. As versões seguintes mostram as diferenças registradas. Os destaques descrevem mudanças no texto; a classificação jurídica de seus efeitos depende de conferência na fonte.

### Executar no computador

Use **Node.js 22 ou superior**, sem necessidade de instalar dependências npm. Depois de baixar o repositório, abra um terminal na pasta do projeto e execute:

```sh
npm start
```

O terminal informa a porta local do servidor. Para gerar o pacote de publicação e executar os testes da aplicação:

```sh
npm test
npm run test:python
```

O build gera um shell leve em `dist/index.html`, um catálogo pequeno em `dist/catalog.json` e um JSON com nome baseado em SHA-256 por norma. A home abre sem carregar o acervo; a busca usa índices compactos e o leitor carrega a norma escolhida. Módulos ESM nativos são publicados em um namespace imutável. A PWA guarda conteúdos consultados, oferece preparo completo explícito e reutiliza arquivos inalterados nas atualizações. Para testar ou compartilhar uma prévia, sirva a pasta `dist/` inteira por HTTP; abrir somente o HTML como arquivo não é suficiente.

A hospedagem usa GitHub Pages. Cada mudança incorporada na `main` passa pelas verificações do workflow antes da publicação.
